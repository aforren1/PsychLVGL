Ubuntu-Medium.ttf is the Ubuntu font, copyright 2010, 2011 Canonical Ltd.,

It is a copy of third_party/lvgl/examples/libs/tiny_ttf/Ubuntu-Medium.ttf
(LVGL v9.6.0). The tests keep their own copy because the forward-test CI jobs
check out this repository without submodules, so the LVGL tree is absent
there. The font is test data only and is not part of the release packages.
